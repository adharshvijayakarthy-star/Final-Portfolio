# Stay Awhile navigation and native fallback

The current ten-route experience uses `../world/` for the finished Blender environment and server-rendered narrative. This directory owns shared navigation, map topology, route names, shell styling and legacy project-hash compatibility.

`GardenNav` and `GardenMap` provide real links, a native modal dialog, keyboard containment, Escape/trigger restoration and cancellable map-path travel. `StayNavigation` connects the overhead lift to the shared world and focuses a committed destination. Quiet reading and reduced motion skip travel animation. The no-JS atlas is a native disclosure with links to all ten routes.

`StayShell` retains the pre-existing Garden evidence hashes used by Quick Discovery. Historical SVG pages and their controllers remain as prior artifacts; the current route pages do not mount their animation systems. Shared map drawings/topology remain in their existing JSON and source files. No new recurring frame loop is introduced by navigation; its focus and legacy hash positioning use bounded one-shot callbacks.

For current architecture, provenance and verification boundaries, see `../world/README.md`, `../world/NARRATIVE_SOURCES.md` and `.codex-tmp/stay-quality/QUALITY_REPORT.md` at the repository root. The former Phase 1 verification is historical and does not validate the final runtime.
