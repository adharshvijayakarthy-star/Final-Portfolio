# public/

Static assets served from the site root, unprocessed.

## What belongs here

- `favicon.ico`, touch icons, `site.webmanifest`
- `robots.txt` / `sitemap.xml` **only** if they are not generated by
  `app/robots.ts` / `app/sitemap.ts` (prefer the generated versions)
- Anything that must be fetched at a stable, predictable URL

## What does NOT belong here

- **Project imagery.** Import it from `src/assets/` instead so that
  `next/image` can hash, resize, and serve AVIF/WebP. Files in `public/` are
  shipped byte-for-byte, at full size, with no optimisation.
- **Fonts.** They are self-hosted by `next/font` at build time from
  `src/lib/fonts.ts`.
- **Stay Awhile environment assets.** When that experience is built, its
  imagery must be imported inside the `(stay-awhile)` route group so it is
  code-split away from Quick Discovery. Anything placed here is reachable
  globally and defeats that separation.

## Conventions

- Lowercase, hyphenated filenames.
- Photographic source in AVIF or WebP; `next/image` handles the rest.
- Vector marks as SVG, with `viewBox` set and fixed `width`/`height` removed.
